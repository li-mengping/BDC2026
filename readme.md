# BDC2026 可复现提交说明

本仓库实现沪深 300 周频横截面排序。训练、预测和结果校验均可在无网络环境运行；数据准备是独立阶段，冻结后的数据通过 `data/manifest.json` 校验。

## 比赛口径

- 评估单位是目标周内的五个评估交易日，而不是固定的自然日名称。
- 单票收益为第 1 个评估交易日开盘买入、第 5 个评估交易日开盘卖出，即 `T+1 open -> T+5 open`。目标周恰好为周一至周五时，文字表现为周一开盘至周五开盘；周五收盘不参与收益计算。
- 训练样本默认只纳入五个交易日齐全的周。这是数据质量策略，不改变比赛公式。
- 结果文件必须是 UTF-8 CSV，字段严格为 `stock_id,weight`；最多 5 只不同股票，权重非负且总和不超过 1。

## 运行与复现

```bash
bash init.sh
bash train.sh
bash test.sh
```

训练和预测不会联网，随机种子为 42。程序发现数据清单缺失、哈希不一致、目标期之后的数据或不完整周时直接失败，不会联网补数。

## 算法与当前生产配置

模型使用日线数据构造的周窗口特征，以 XGBoost `rank:pairwise` 做横截面排序，预测结果直接选择得分最高的 5 只股票并等权。绝对组合收益是主选择指标；相对全股票均值的 excess return、RankIC、最差折和波动率仅作为诊断和 Pareto 门禁。历史实验中的其他模型族和超参数候选未通过完整门禁时不会进入生产目录。

## Docker 发布

```bash
bash package.sh
```

脚本从自身位置定位仓库，使用 Dockerfile 中固定的 Python 3.10 slim digest 构建 `bdc2026:latest`，不使用镜像代理回退。结果写入被 Git 忽略的 `dist/`：包含镜像 tar、compose 文件、冻结行情及其 manifest/成分股快照、本文档、空 `output/`/`temp/` 和 `SHA256SUMS`。训练与预测容器必须使用 `--network none`；原始行情 CSV 不提交 Git。

## 证据与限制

审计、约束矩阵和每轮实验证据位于 `.agents/`。当前正式候选是在已声明的滚动折、特征空间和预算内停止搜索的结果，不宣称数学意义上的全局最优。已观察 holdout 只可报告，不能用于重新选型。

外部资料登记在 `.agents/audit/external-research.md`；没有登记来源、日期和适用性判断的资料不得进入训练或提交。
