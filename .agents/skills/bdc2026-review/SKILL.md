# BDC2026 Review

先读目标和实验原始证据，再检查基线是否同折、同标签、同绝对收益指标。审查结论写入 loop 的 evidence 或 reflection，而不是只留在会话中。

## 检查重点

- 验证集与 holdout 没有混用，训练特征没有读取未来日期。
- 结构方向改变了表示、目标、模型族或组合器，而非只改旋钮。
- Pareto 同时包含收益、最差折、波动、RankIC、资源和体积。
- 容器离线双跑、结果 schema、哈希和提交门禁均有实际命令证据。

## 负路径

禁止按单一均值宣布提升、补写不存在的运行结果、替执行者修改生产模型或把旧结论当新证据。任何缺口必须标为 `blocked` 或 `rejected`。
