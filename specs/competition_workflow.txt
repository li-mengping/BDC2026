;===============================================================
; @id official-five-session-return
; 比赛收益公式与官方评分行为。
;===============================================================
GIVEN 一个股票具有按时间排序的五个评估交易日行情。

WHEN 系统计算该评估窗口的收益率。

THEN 收益使用第一个评估交易日开盘价买入和第五个评估交易日开盘价卖出。
THEN 改变第五个评估交易日收盘价不会改变收益率。

;===============================================================
; @id full-week-training-policy
; 训练样本日历政策独立于比赛收益公式。
;===============================================================
GIVEN 行情中同时存在完整周一至周五和缺少交易日的自然周。

WHEN 系统按正式训练政策构造周样本。

THEN 只采用完整周一至周五样本。
THEN 缺失周不会被更早历史周跨越拼接。

;===============================================================
; @id competition-cutoff-guard
; 目标期数据泄漏禁区。
;===============================================================
GIVEN 冻结训练数据的截止日早于目标评估周。

WHEN 训练或特征流程收到目标评估周及之后的行情。

THEN 流程拒绝使用目标评估期行情。

;===============================================================
; @id offline-workflow
; 离线训练与预测。
;===============================================================
GIVEN 行情数据、成分股清单和模型依赖已经本地冻结。
GIVEN 运行环境无法访问网络。

WHEN 用户依次执行训练和预测流程。

THEN 训练流程生成可加载的模型产物和审计元数据。
THEN 预测流程生成符合比赛格式的投资组合。

;===============================================================
; @id result-contract
; 结果文件约束。
;===============================================================
GIVEN 预测流程已经生成投资组合。

WHEN 系统校验最终提交结果。

THEN 结果只包含股票代码和权重两列。
THEN 结果包含一至五只不同股票。
THEN 每个权重非负且所有权重之和不超过一。

;===============================================================
; @id reproducible-run
; 可复现性。
;===============================================================
GIVEN 相同的冻结数据、配置、依赖和随机种子。

WHEN 用户重复执行完整训练与预测流程。

THEN 两次最终结果内容完全一致。
