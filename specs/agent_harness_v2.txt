;===============================================================
; @id immutable-achieved-goal
; 已完成 Goal 的历史完整性。
;===============================================================
GIVEN 一个已经达到 achieved 状态的 Goal。

WHEN 新证据证明旧闭环不完整。

THEN 系统拒绝直接回写该 Goal。
THEN 新 Goal 通过 supersedes 关系保存纠偏链。

;===============================================================
; @id resumable-agent-handoff
; Agent 交接和反思证据。
;===============================================================
GIVEN 一个由执行 Agent 完成但尚未审查的迭代。

WHEN Agent 将工作交接给审查角色。

THEN 交接包含输入、输出、验证证据、限制和下一动作。
THEN 反思包含预期、观察、差异、失败类别、学习和修正动作。

;===============================================================
; @id commit-contract
; Agent 提交消息契约。
;===============================================================
GIVEN 一个准备提交的 Agent 变更。

WHEN 系统执行提交前校验。

THEN 提交消息包含所有规定的 Agent 字段。
THEN 提交记录关联当前 Goal、loop 和验证证据。
