先定标签
日频/周频/月频未来收益、超额收益、行业中性残差收益、波动调整收益，或直接用横截面 rank/quantile label。LTR 里每个调仓日就是一个 group/query。

价格量价特征
1/5/20/60/120 日收益，短反转、长动量、波动率、偏度、最大回撤、成交量变化、换手率、Amihud illiquidity、high-low range、gap、volume-price correlation。高频可加 order imbalance、spread、depth、trade flow。

基本面和风格因子
size、value、profitability、quality、growth、leverage、accruals、earnings yield、ROE/ROA、gross margin、analyst revision。传统资产定价和 ML 论文反复发现 momentum、liquidity、volatility 等仍是重要预测族。(academic.oup.com)

横截面处理
每天截面 winsorize、rank/z-score、行业/市值/beta 中性化、缺失值分组填充。金融里很多模型直接用“截面 rank 后的特征”，因为更稳也更贴近排序目标。

关系特征
行业、概念、供应链、共同基金持仓、新闻共现、收益相关、lead-lag 构图；图模型/超图模型会把这些作为边或超边。综述里也把数值、关系、另类数据作为量化投资数据处理的主要模态。(arxiv.org)

文本和另类数据
财报、公告、新闻、研报、电话会、社媒情绪可转成 sentiment、事件标签、embedding、主题暴露。LLM 现在更常被用于生成因子假设、解析文本、构建公司关系，而不是直接裸预测价格。

筛选和验证
看 IC/RankIC、ICIR、decile monotonicity、top-bottom spread、turnover、因子相关性、交易成本后 Sharpe、最大回撤。必须 walk-forward/purged split，避免未来函数、幸存者偏差、公告滞后和复权泄露。
